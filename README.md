# Signed E-Mail-Signatur

[HTML-Datei herunterladen](https://github.com/cem-gdk/signed-signatur/raw/refs/heads/main/Signed-Signatur.html)

Öffne die heruntergeladene Datei im Browser und kopiere die angezeigte Signatur mit **Strg+A**, **Strg+C** (Mac: **⌘A**, **⌘C**). Füge sie in Proton unter **Einstellungen → Identität und E-Mail-Adressen → Anzeigename und Signatur** in das Signaturfeld der gewünschten Absenderadresse ein. Klicke auf **Aktualisieren**.

In jeder Kontaktzeile bilden Icon und Text einen gemeinsamen Link. TikTok, Instagram und der Shop verwenden HTTPS, die Telefonnummer verwendet `tel:+4915734285869`.

Die Signatur lädt ihre fünf PNG-Dateien aus `assets/`. Die vier Buttons erscheinen in 18 × 18 px mit weißem Symbol auf `#666666`. Die editierbare Logovorlage liegt in `source/`.
